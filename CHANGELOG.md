# Changelog

Release notes for the WP HTTP QUERY plugin live on the
[GitHub Releases page](https://github.com/moonmeister/wp-http-query/releases). Each release's notes
are drafted from the titles of the pull requests merged since the previous one; see
[RELEASING.md](RELEASING.md).

Unreleased changes on `main` are in the
[Nightly prerelease](https://github.com/moonmeister/wp-http-query/releases/tag/nightly) and the
[merged pull requests](https://github.com/moonmeister/wp-http-query/pulls?q=is%3Apr+is%3Amerged).
