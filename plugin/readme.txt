HTTP QUERY (RFC 10008) support for the WordPress REST API, on stock core.

== Description ==

Minimal readme so the plugin's metadata is machine-readable. The full WordPress.org readme
(longer description, FAQ, screenshots) is tracked in issue #45:
https://github.com/moonmeister/wp-http-query/issues/45

Adds the HTTP QUERY method to the WordPress REST API with no core patch. Nothing gains QUERY by
default: a route registers it, a site lists routes in a filter, or a site enables a preset on
Settings > HTTP QUERY. See README.md in this directory for how to use it.
